# Security Policy

## Reporting a vulnerability

Please do not report suspected security vulnerabilities in a public GitHub issue.
Use GitHub's private vulnerability reporting feature for this repository instead.
Include a clear description, affected version or commit, reproduction steps, and
security impact. Do not include production credentials, personal data, or customer
data in the report.

We will acknowledge a report within 7 days and provide status updates while we
validate, remediate, and coordinate disclosure.

## Supported versions

Only the latest released DagSentry version receives security fixes. Development
snapshots and superseded releases should be upgraded before requesting support.
